Oficjalna strona internetowa **Salonu Kosmetologicznego Obsession** w Kozienicach, prowadzonego przez Monikę Molendę. Projekt został stworzony z myślą o elegancji, nowoczesnym wyglądzie oraz łatwym dostępie do pełnej oferty zabiegowej dla klientów z Kozienic i okolic.

---

## ✨ Główne cechy (Features)

- **Nowoczesny i elegancki design** dopasowany do specyfiki branży beauty (przejrzysty interfejs, spójna kolorystyka).
- **Pełna responsywność (RWD)** – aplikacja webowa wygląda i działa bezbłędnie na urządzeniach mobilnych, tabletach i desktopach.
- **Zoptymalizowane SEO (Search Engine Optimization)** – precyzyjnie dobrane tagi meta, Open Graph, Twitter Cards, a także Schema.org (LocalBusiness) co znacząco ułatwia pozycjonowanie.
- **Dynamiczna i płynna nawigacja** ułatwiająca przeglądanie oferty (Zabiegi, Cennik, Galeria, O mnie, Kontakt).
- **Modułowa architektura JavaScript** (`ES Modules`) zapewniająca porządek i wysoką reużywalność kodu na różnych podstronach.

## 🛠️ Technologie

Projekt opiera się na wydajnym i czystym stosie technologicznym bazującym na natywnym środowisku przeglądarki:

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS / ES Modules)
- **Architektura:** Podejście oparte na niezależnych, reużywalnych komponentach i funkcjach w czystym JS.
- **Wydajność:** Ładowanie zasobów asynchronicznie, dostosowanie metadanych pod kątem zaleceń Core Web Vitals.
- **Konfiguracja:** Zoptymalizowane pliki `robots.txt` oraz `sitemap.xml` dla sprawniejszego indeksowania przez wyszukiwarki.

## 📂 Struktura katalogów

Poniżej znajduje się ogólny zarys struktury plików w projekcie:

```text
StronaMonika/
│
├── animations/           # Animacje i skrypty/pliki odpowiedzialne za przejścia
├── backend/              # Zasoby i dane współdzielone (zoptymalizowane zdjęcia, favicony, ikony)
├── modules/              # Uniwersalne, eksportowalne moduły JavaScript używane w całym projekcie
├── pages/                # Pliki HTML poszczególnych podstron (Zabiegi, Cennik, Kontakt itd.)
├── pages-js/             # Logika JavaScript dedykowana wyłącznie dla konkretnych podstron
├── styles/               # Arkusze CSS (główne style i style dedykowane dla podstron)
│
├── index.html            # Główny punkt wejścia aplikacji (Strona główna)
├── index.js              # Główny kontroler logiki dla strony głównej
├── sitemap.xml           # Mapa witryny ułatwiająca indeksowanie
└── robots.txt            # Reguły dostępności dla robotów indeksujących
```
